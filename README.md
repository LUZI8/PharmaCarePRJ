# 💊 PharmaCare

PharmaCare is a full-featured online pharmacy web application designed to provide users with a simple and convenient way to browse healthcare products, manage their shopping cart, reserve prescription medications, and access useful health tools.

## ✨ Features

* 🛒 Browse and purchase pharmacy products
* 🔍 Search, filter, and sort products
* 💊 Prescription medication reservation system
* 🛍️ Shopping cart management
* 👤 User registration and authentication
* 🔐 Forgot and reset password functionality
* 📧 Email verification
* 📊 BMI / Health Metrics Calculator
* 🏷️ Product categories
* 📦 Product availability and stock information
* 🌙 Dark mode support
* 📱 Responsive and user-friendly interface

## 💊 Prescription System

PharmaCare supports prescription-only medications through a reservation system. Prescription products are clearly identified and handled separately from regular over-the-counter products.

## 🔎 Product Search & Filtering

Users can find products using:

* Product name
* Category
* Minimum and maximum price
* Alphabetical sorting
* Price sorting
* Prescription-only filtering

## 🧮 Health Metrics Calculator

The website includes a BMI calculator that allows users to enter their:

* Age
* Height
* Weight
* Gender

The calculated result is provided for educational purposes and is not intended to replace professional medical advice.
